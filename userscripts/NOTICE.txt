The local adapter is supplied as source in ../userscripts.js,
../userscript-extension/ and ../torn-helpers/session-guard.js.
FF Scouter's generated extension wrapper is distributed under GPL-3.0.
SHA-256 hashes and pinned upstream source versions are in sources.json.
These scripts have their own display settings. FF Scouter automatically uses
the tracker's saved FFScouter key, falling back to its Torn API key. Requests
use an authenticated local proxy; the saved key is not copied into the page.
TornW3B synchronizes viewed auction listings to weav3r.dev, as described by
the upstream script. Each integration can be disabled in Settings / Torn helpers.
