Torn rules

Plays by the rules. You press every button.

  1. 01

    Your key stays on your PC

    A Limited Access key, saved locally. It is used with the Torn API and FFScouter. With the Premium connection on (default), it is also sent to lrxe8.com to verify your Torn ID and is not stored there.

  2. 02

    Display only

    Helpers never click, attack, buy or send anything for you. They only add information to the page.

  3. 03

    Only the tab you look at

    Helpers run on the focused Torn tab and make no extra requests to Torn's pages.

  4. 04

    A switch for everything

    Every helper, add-on and connection can be turned off in Settings.

Release notes

What changed, version by version.

Updates install from inside the app. Your key, settings and data stay where they are.

v1.6.13Safer updates and add-ons2026-11-13Latest
  • An update that fails half-way puts the previous version back by itself.
  • TornTools is installed only when its package carries TornTools' own signature, as Chrome checks it.
  • A Torn tab that keeps changing pages on its own is stopped until you click in it. It has its own setting.
  • Xanax Today shows an exact number only when it is exact, and marks it with ≥ or ≤ otherwise.
  • Hospital alerts also fire when you or a target leave hospital early.
  • Saving a new key, prices like "1,500k", FFScouter registration and the poker odds labels are fixed.
v1.6.12Torn rules and privacy2026-11-12
  • The Rehab message button no longer clicks anything on Torn. It types into a chat box you opened, and you press Enter yourself.
  • New setting Settings → App → Premium membership connection. Turn it off and your key is never sent to the membership service.
  • The Torn ToS table and the sign-in notice now list exactly what is shared, and with whom.
  • Importing a Torn session no longer signs you out when a single cookie is rejected.
  • Torn's own menus work again with the session guard, which now has its own setting.
  • Switching API keys can no longer mix another player's data into your history.
  • The light theme no longer makes the sign-in screen hard to read.
v1.6.11Automatic membership2026-11-11
  • Signing in to the app connects Premium with your saved Torn account. No extra buttons or checkboxes.
  • Membership sessions renew on their own after they expire or the app restarts. Temporary failures never affect the free tools.
  • Sending Xanax activates membership right away, even before the sender opens the app. Two Xanax add 30 days.
  • A transfer is never counted twice, and no other account can claim your membership.
v1.6.10Automatic Xanax payments2026-11-11
  • Xanax payments are matched from Torn's official item logs, including notices that only say "some Xanax".
  • Older unmatched transfers were settled automatically at the price that applied when they were sent.
  • Membership cards and the member list show real Torn names. Search works with names and IDs.
  • Premium tools open directly for members. Saved profiles survive pauses, expiry and renewal.
v1.6.9Premium workspaces2026-11-11
  • Optional Premium workspaces: appearance profiles, helper filters, player comparisons, event goals, travel strategies and saved merit plans.
  • The membership connection runs over public HTTPS at lrxe8.com, with no VPN or extra setup.
  • Saved Premium settings come back when you renew.
  • All existing tools stay free.

Is it free?

Yes. All current tools and Torn API data access are free. Premium is optional and paid with in-game Xanax.

Which API key do I need?

A Limited Access key you create in Torn's preferences. The app links you there on the sign-in screen.

Is it allowed in Torn?

It uses the official API with your own key, and its helpers only display information. It is an independent project, not an official Torn product.

Can I use it on Mac?

Not yet. The Mac version is in development; only the Windows build can be downloaded.

How do I send an idea or a bug?

Use the Feedback button in the app, or open an issue on GitHub.
