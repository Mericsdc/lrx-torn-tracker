Release notes and downloads

Before you open it.

Are the current tools free?

Yes. Existing tools and Torn API data access remain free. Premium adds optional advanced analysis; real Xanax payments are currently closed.

Where does my API key go?

Your key is saved locally. Torn and FFscouter supply the relevant data. Connecting the optional membership service requires separate consent before identity verification.

Can I use it on Mac?

The Mac version is in development. Only the Windows build is available to download. There is no announced Mac release date.
