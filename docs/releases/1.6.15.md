# LRX Torn Tracker v1.6.15

## Your saved keys are encrypted

- Your Torn API key, FFScouter key and log key are now saved encrypted with Windows DPAPI, so only your Windows account on this PC can read them. Keys you already saved are encrypted the first time v1.6.15 starts; there is nothing to do.
- If the app's data folder is moved to another Windows account or PC, the sign-in screen says why it asks for your key again.
- Going back to an older version means entering your key once more.

## A calmer Overview

- The **Live timers** strip no longer has the LIVE badge or the "updated … ago" line. Each countdown is its own tile with a small drawn icon.
- While you fly, the trip shows once, in **Status**: the route ("China → Torn") and a **Landing** countdown that ticks every second, with the landing time in TCT. The travel chips in the Bars header and on the profile card are gone while you travel and come back when you land.

## Safety fixes

These come from a review of the app's code:

- Torn tabs and their pop-ups can no longer open an address on your own computer, where the app's own page runs.
- The display-only helpers can only make the kinds of web requests they need.
- TornTools packages are checked more strictly when they are unpacked.
- The weekly faction report stops when another player signs in, so the previous faction is never looked up with the new key.
- Smaller fixes: charts keep their own colours when a page has several, the feedback window no longer opens under a Torn tab, and Baldr's Levelling Targets no longer sends a refresh while the previous one is still loading.

## Update

Existing users can install through the app's update button. Local keys, settings and profiles are preserved. New users can download `LRX-Torn-Tracker-Windows-x64.zip`, extract it and run TornTracker.exe.
