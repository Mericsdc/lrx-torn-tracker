# LRX Torn Tracker v1.6.10

## Automatic Xanax payments

- Fixed transfers whose notification says "some Xanax" without an amount. The collector now reads exact sender/item quantities from official Item receive logs (4103), without guessing.
- Existing unresolved transfers are reconciled automatically. Transfer-time pricing and any existing membership time are preserved.
- Durable log/event links prevent duplicate awards across retries, restarts and workers. Non-Xanax items are ignored.
- Replaced the payment approval/rejection form with an informational automatic-payment ledger.

## Names and simpler access

- Membership cards and the member directory show verified Torn player names. Search supports names and IDs.
- Replaced separate connection and analysis acceptance checkboxes with clear data-use notices. Connect account remains a user action; saved keys are not forwarded silently.
- Premium members can use advanced tools directly. Analysis can still be paused, and saved profiles survive pauses, expiry and renewal.

## Install or update

- Existing users: use the in-app update button to install v1.6.10. Your key, settings and local data are preserved.
- New users: download `LRX-Torn-Tracker-win32-x64-1.6.10.zip`, extract it and open `TornTracker.exe`.
- Windows only; Mac remains in development. Existing free features stay free.
- Operators: the receiver key needs Item receive (4103) log access. Ordinary app login keys can remain Limited Access.

Validation: 81 automated tests, integrated Premium/advanced-module UI checks and Windows Electron startup checks. The shared service was checked against official read-only Torn responses; no items are sent automatically.
