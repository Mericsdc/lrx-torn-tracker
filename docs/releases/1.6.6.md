# LRX Torn Tracker v1.6.6

## What's new

- FF Scouter automatically uses the API key saved in Torn Tracker. No second key entry is needed. Verified on real Torn profile and active ranked-war pages against live FFScouter results.
- Bundled FF Scouter V2 and TornW3B Bazaars, with upstream licenses and source hashes included.
- Added Weav3r to the browser shortcuts and animated shortcut collapse when multiple tabs are open.
- Added persistent faction target groups, bulk assignment, filtering, and group labels on war rosters.
- Added five themes, appearance settings, and a passive live fight health-analysis overlay.

## Fixes

- Fixed manual API-key entry and added Paste, a character counter, Caps Lock feedback, and clearer login errors.
- Fixed Xanax effective-stat calculations applying the active penalty twice.
- Fixed sidebar navigation loops, duplicate session cookies, and stale RFC tokens on outgoing Torn requests.
- Improved window sizing, tab creation, sleeping-tab titles, and native-view visibility.
- Updates follow the selected theme and fully close and relaunch the app after installation.

## Install or update

- **Existing users:** use the update button in Torn Tracker. The updater checks the package's SHA-256 before installing.
- **New users:** download `LRX-Torn-Tracker-win32-x64-1.6.6.zip`, extract it, and run `TornTracker.exe`.
- API keys and personal data are not included in these downloads. Updates preserve each user's local data.

Validation: 12 automated tests, UI and packaged Electron smoke tests, and live FF Scouter checks on Torn profile and ranked-war pages.
