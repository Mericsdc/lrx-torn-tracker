# LRX Torn Tracker v1.6.21

## Travel Country Card Flag Backdrops

- **SVG Flag Backdrops for All 11 Travel Destinations:** Added crisp, offline-ready vector flag backdrops (`Mexico`, `Cayman Islands`, `Canada`, `Hawaii`, `United Kingdom`, `Argentina`, `Switzerland`, `Japan`, `China`, `UAE`, `South Africa`) behind each card in **Travel Profit › Country Cards**, including the official State of Hawaii flag and stylized Mexican and Cayman Islands coats of arms.
- **Smooth Gradient Blending & Readability Across All 5 Themes:** Applied dual-axis CSS gradient masking (`mask-image`) so each flag blends seamlessly into Obsidian, Ocean, Forest, Amethyst, and Light themes while keeping profit figures, stock badges, flight times, and observation timestamps crisp and readable.
- **Motion & Accessibility Polish:** Added subtle hover/active depth transitions that automatically respect `prefers-reduced-motion` and the in-app **Animations** toggle, and kept long flight durations on a single line.

## Update

Existing users can install through the app's update button. Local keys, settings and profiles are preserved. New users can download `LRX-Torn-Tracker-Windows-x64.zip`, extract it and run TornTracker.exe.
