# LRX Torn Tracker v1.6.8

## Automatic update notifications

- The app checks for new releases on startup and every minute while running, including the first launch before entering a Torn API key.
- A new version opens the themed **Update released** dialog asking whether you want to update. Choosing **Later** keeps the update button pulsing until installation, including in the workspace bar while a Torn tab is active.
- Each release is announced once per app session. The prompt waits while the window is hidden or another dialog is open, and checks resume when you return or regain connectivity.
- Temporary connection failures preserve an update already found. Concurrent checks share one request.
- Reduced-motion and disabled-animation preferences retain a static update indicator. The existing automatic-check preference is respected, and installation requires your choice.

## Install or update

- **Existing users:** use the update button to install v1.6.8 and enable the new notification behavior. The app verifies the download and restarts after installation.
- **New users:** download `LRX-Torn-Tracker-win32-x64-1.6.8.zip`, extract it, and run `TornTracker.exe`.
- Your saved API key, settings and local data are preserved.

Validation: 12 automated tests, UI smoke checks for startup and live release detection, deferred notifications, pulsing, offline recovery and concurrent checks, plus packaged Electron smoke tests.
