# LRX Torn Tracker v1.6.7

## Themed update window

- The update screen now uses the main app's card surfaces, fonts and buttons in all five themes.
- Current and latest versions are displayed side by side. Release notes show formatted headings, lists, bold text and code.
- Long notes scroll inside the dialog, keeping the action buttons visible even at 480 x 400.
- Download progress and errors appear in the same themed window, with keyboard navigation and focus restored after closing.
- The top update button and Settings > Updates open the same screen, including when the app is already up to date.

## Install or update

- **Existing users:** use the update button in Torn Tracker to install v1.6.7. The app verifies the download and restarts after installation.
- **New users:** download `LRX-Torn-Tracker-win32-x64-1.6.7.zip`, extract it, and run `TornTracker.exe`.
- Your saved API key, settings and local data are preserved.

Validation: 12 automated tests, UI checks across all five themes and the compact layout, and packaged Electron smoke tests.
